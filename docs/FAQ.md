# Frequently Asked Questions

## Does it work without a PC?

Yes. Labs, both learning paths, the offline coach, Living Engine, cached intelligence, rule practice, analyst terminal, search and local portfolio work standalone.

## Does it run Security Onion, Splunk or SOAR on the phone?

No. Those are service-heavy main-lab capabilities. Mobile provides truthful local learning tools and an optional future connection to real services.

## Does it scan the phone or local network?

No. It observes only basic connection availability/type. It does not capture packets, enumerate devices, inspect other apps, contacts or messages, or claim vulnerability from connection metadata.

## Does Offline Coach send prompts online?

No. It is a packaged deterministic reasoning coach. Paired or vendor-specific AI providers must be separately selected and clearly labelled when added.

## Can AI pass a lab for me?

No. AI may guide reasoning. The learner makes the decision and records evidence. Signed independent evidence remains a main-platform workflow.

## Is a CVE or KEV record proof that I am affected?

No. Validate asset/version presence, reachability, exploitation evidence, consequence and controls before asserting exposure or priority.

## Can Terminal execute device commands?

No. It interprets a small documented command set over embedded synthetic security rows and rejects unknown commands.

## Why does iOS need a Mac?

Apple requires Xcode on macOS for the final native compile, simulator/device test and code signing. The shared app and iOS project are still developed from the same public source.

## How do updates reach other phones?

Android testers can receive a verified APK; iOS testers use Xcode or TestFlight. Public stores require separately protected release signing credentials.

## Does the repository contain secrets?

It is designed not to. Public source contains synthetic evidence and public feed URLs. CI checks for credentials, private keys and private endpoint patterns. Report any suspected disclosure privately under `SECURITY.md`.
